# Dataset Source — Brazilian E-Commerce Public Dataset by Olist

## Source Link
* **Kaggle Dataset:** [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

## Local Setup Instructions
1. Download the dataset archive from Kaggle.
2. Extract the 9 raw CSV files into `data/raw/`:
   * `olist_customers_dataset.csv`
   * `olist_geolocation_dataset.csv`
   * `olist_order_items_dataset.csv`
   * `olist_order_payments_dataset.csv`
   * `olist_order_reviews_dataset.csv`
   * `olist_orders_dataset.csv`
   * `olist_products_dataset.csv`
   * `olist_sellers_dataset.csv`
   * `product_category_name_translation.csv`

> **Note:** Raw `.csv` files in `data/raw/` are excluded from Git version control via `.gitignore`.
